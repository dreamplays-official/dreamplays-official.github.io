Dreamplays HQ (officially registered under MSME as Dream Plays Official) is an independent Indian EdTech and software utility startup. Headquartered in Rudrapur, Udham Singh Nagar, Uttarakhand, the platform was founded in 2026 by student innovators Arnav Tyagi and Yugank Vishnoi. The organization is known for developing open-access, lightweight, client-side browser tools aimed at eliminating socio-economic and hardware barriers for students and digital creators. The company is formally recognized under the Startup Uttarakhand initiative and holds an official MSME registration (UDYAM-UK-12-0098916).

History and Smartphone-Only Development

The conceptualization of Dreamplays HQ began as a collaborative project between school peers Arnav Tyagi and Yugank Vishnoi. Observing that mainstream graphic design and programming tools required expensive computing hardware, they set out to construct a free, decentralized alternatives layout.

Due to a lack of traditional desktop hardware, the founders adopted an unconventional engineering workflow. The entire code repositories, vector graphics, platform assets, and early software updates were written, compiled, and deployed using strictly Android mobile smartphones. Following its public launch, the project expanded its infrastructure, eventually gaining international users across India, the United States, and China.

Core Projects and Software Ecosystem

The primary focus of Dreamplays HQ is the development of client-side web tools that run seamlessly on low-spec hardware and mobile browsers.

AYARTSTUDIO

AYARTSTUDIO is the primary creative framework hosted by the ecosystem. Operating on a 100% free model, it functions as an interactive web portal optimized for lower-tier mobile and desktop browsers. Its key features include:

  • Online Grid Maker: A technical browser extension that overlays scale matrices over user-submitted graphics, widely used by physical sketch artists for layout mapping.
  • Art Education Syllabus: Accessible modules covering pencil gradients, perspective frameworks, and geometric anatomy guides tailored for student artists.

DreamPlays Mobile Application Hub

The platform manages an active Android sandbox application designed to act as an offline-capable nexus. It features an asynchronous engine layer that connects simple static web elements with system background processing tasks. The framework provides background token handshakes, local storage clearouts, and structured analytics logging panels.

Technical Architecture

The software stack at Dreamplays HQ is structured to minimize client-side payloads and bypass continuous computational rendering server costs.

  • Frontend Framework: Built natively using vanilla HTML5, Tailwind CSS, and ES6+ JavaScript, which ensures compatibility with simple mobile web views.
  • Backend and Cloud Routing: Leverages secure Google Firebase endpoints to handle decentralized subscriber tokens and verification loops, while hosting is distributed directly over GitHub Pages architecture.

Corporate Structure and Initiatives

Leadership: Arnav Tyagi directs frontend optimization and responsive UI/UX modules, drawing from 4 years of open-source development. Yugank Vishnoi serves as Chief Infrastructure Engineer, overseeing data architecture, full-stack environments, and cloud databases.

Monetization Model: To remain free to end-users, core tool pipelines rely on non-intrusive advertisements and enterprise sponsorships.

Dream AI Roadmap: The organization has announced plans for "Dream AI," an upcoming browser-integrated client-side helper designed to provide lightweight real-time code parsing and layout tips directly within the sandbox.
